# XBullet.EasyTesting.Aspire

Starts Aspire application models, discovers resources and endpoints, and captures diagnostics.

```xml
<PackageReference Include="XBullet.EasyTesting.Aspire" Version="VERSION" />
```

## Primary APIs

- <xref:XBullet.EasyTesting.Aspire.AspireTestHost> starts the fluent Aspire test workflow.
- <xref:XBullet.EasyTesting.Aspire.AspireTestHostBuilder`1> configures startup and readiness.
- <xref:XBullet.EasyTesting.Aspire.AspireTestApplication`1> accesses resources and owns shutdown.

See the [Aspire guide](../../guides/aspire.md).
