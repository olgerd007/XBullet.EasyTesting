# XBullet.EasyTesting.Testcontainers

Reusable container resources and built-in modules for integration-test scenarios.

## Primary APIs

- <xref:XBullet.EasyTesting.Testcontainers.TestcontainerModuleExtensions> configures built-in services.
- <xref:XBullet.EasyTesting.Testcontainers.TestcontainerExtensions> registers arbitrary containers.
- <xref:XBullet.EasyTesting.Testcontainers.TestcontainerResource`1> owns lifecycle and diagnostics.
